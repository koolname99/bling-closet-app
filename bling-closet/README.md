# Bling Closet

Bling Closet is a stunning React web application built for a boutique clothing store. Designed with a vibrant pink aesthetic, this SPA (Single Page Application) highlights the store's beautiful products and features direct links to their official Facebook page for smooth customer communication and sales.

## Features
- **Modern Landing Page**: A visually appealing hero section and new arrivals grid.
- **Product Catalog**: A comprehensive 'Products' page displaying all available items.
- **Customer Reviews**: Dynamic review cards with customer feedback screenshots.
- **Social Media Integration**: Direct "Message to Buy" buttons linking to the store's official Facebook profile.
- **Responsive Navigation**: Easy-to-use Navbar connecting Home, Products, About, and Contact pages.

## Tech Stack
- Frontend: React 19, React Router DOM v7
- Build Tool: Vite
- Styling: Vanilla CSS with custom design system variables

## Getting Started

To run this project locally, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine. 

### Instructions
1. Navigate to the project directory in your terminal:
   ```bash
   cd bling-closet
   ```

2. Install the necessary dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and visit the URL provided in your terminal (usually `http://localhost:5173`).

## Project Structure
- `src/components`: Reusable UI components like Navbar, Footer, and Product Cards.
- `src/pages`: Main page layouts (Home, About, Contact, Products).
- `src/utils`: Mock data used for populating products and customer reviews.
- `src/assets`: Images, banners, and feedback screenshots used across the application.
